# EduBridge
 
Project Title: 
--------------
EduBridge - Bridging Students, Faculty and Administration in a unified space.

Selected Domain: 
----------------
Web Development

Problem Statement:
------------------
 “Campus Bridge – Integrated Academic LMS + Coding Skill Development Platform”

Abstract:
---------
In the rapidly evolving landscape of higher education and technological advancement, there is a growing demand for platforms that not only streamline academic processes but also foster skill development. EduBridge is an innovative web-based platform that bridges the gap between academic learning and technical skill enhancement for university students. The system is designed as a dual-purpose solution that integrates a Learning Management System (LMS) with an interactive Coding Practice Module, tailored to meet both academic and industry-driven needs.

The LMS component of EduBridge enables students to access their course materials, assignments, attendance, timetable, and results through a centralized and intuitive dashboard. Faculty members can efficiently upload content, manage assessments, and track student performance. The UI is designed to be modern, responsive, and easy to navigate, ensuring a seamless user experience.

Simultaneously, the coding practice environment within the platform empowers students to build their technical proficiency in Data Structures, Algorithms, and Competitive Programming. It includes a compiler, language selection, and problem-solving modules with real-time feedback. The system supports structured learning paths aligned with placement preparation and career readiness.

Built using HTML, CSS, JavaScript, and Firebase, EduBridge ensures secure login/authentication, real-time data storage, and scalable access. The integration of a chatbot enhances student support by answering common queries instantly, adding to the platform’s smart ecosystem.

By combining academic tracking with technical upskilling, EduBridge prepares students for both university success and industry expectations. The project represents a forward-thinking approach to education, where learning is not confined to classrooms but expands into personalized, skill-based development. This solution is particularly valuable for institutions aiming to deliver holistic education through technology.

Tech Stack Used:
----------------
-> Frontend: HTML, CSS, JavaScript, Bootstrap
-> Backend: Firebase (Auth, Firestore, Hosting)
-> AI Assistant: Gemini AI API
-> Version Control: Git + GitHub
-> Firebase Authentication: Secure user sign-in
-> Firestore DB: Real-time database for user data
-> Bootstrap: Ensures responsive layout
-> Firebase Hosting: For live deployment
